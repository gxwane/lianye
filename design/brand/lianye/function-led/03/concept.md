# 03：滑痕存页

状态：第二次文字概念登记，等待总审；尚未制作视觉稿。此前“拖影长帧”已撤回。只阅读本轮 brief，未读取其他组或旧图稿。

## 1. 方向名与具体结构

**滑痕存页。** 主体是一块宽的竖向滑动印迹，而非画面外框。印迹下端是平直的宽尾，沿一条轻微向左弯的轨迹上行，在左上方以钝圆头停止。上下长度约为最大宽度的 2.2 倍；轨迹只向一侧轻弯，不转回、不折叠，不形成 S/Z。外轮廓没有另贴的速度线，平尾、弯曲侧缘和钝圆停止端就是一次上滑留下的整体形状。

从这块实色印迹内部镂出**一整段连续内容**：一根竖向留白的页边栏连接上方一个近方形内容区与下方一个较长的内容区。两个内容区宽度相近、长度不同；它们的左边对齐，连接边栏的留白从上贯通到下，最后在印迹下端开放。内部不是两张卡片，也没有一条分隔画面的边框：它是一块有凹凸边缘、贯通出口的负空间，像长页面中的两个连续内容段被完整带出。方形区与长区均保留平直边缘，和外部的弧形运动轮廓形成明显区别。

外面的宽滑痕对应一次持续向上滑动，里面的内容保持统一纵向对齐，构成被保留下来的画面内容。制作时必须让内部内容占主体宽度约一半，避免缩成点线装饰；不加手指、箭头、相机、折角、光束或多条速度线。

## 2. 可见的产品动作

**主动作是滚动期间，把前后遇到的内容留在同一个连续结果里。** 运动直接决定外轮廓：有一个起点、一个宽而连续的滑动轨迹和一个停下来的平端。完整保留直接决定内部结构：上下两个内容段共用一根不断开的页面边栏，第二段沿纵向接续，而不是旁边另外出现一张画面。

本稿首先希望建立“滑过一段内容，将它留下”的联想。内部上小下长的两个内容区提供跨越一屏的证据，贯通的留白边栏提供它们属于同一连续页面的证据。没有使用闭合长方框承载功能语义，也没有用叠卡数量解释长图。

这不是截取、对位、编辑全部动作的流程图。不宣称一个抽象印迹可让人立即说出“自动长截图”；最低通过条件是，不显示名称时至少能认出“有内容留在一段滑动轨迹中”，而不是只看见空白弯条。

## 3. 误认风险与处理

- **画笔、涂抹或橡皮擦：** 这是最主要风险。外轮廓不得出现刷毛、尖笔端、飞溅或渐淡拖尾；内部内容必须保留清楚的块面和共用页边栏，不能只是被擦出两条白线。圆头只占总长度的小部分，不要画成一根普通画笔。
- **阅读或笔记应用：** 保留连续内容有真实联系，但可能误读成阅读器。外轮廓须形成明确的一次上滑痕迹，不使用普通纸张轮廓、装订线或折角。这个风险不能完全靠造型排除，应在最终图稿中诚实比较。
- **字母标识、逗号或羽毛：** 内部负空间不要做成三条等距横线，也不把外形收成尖尾。主体不依赖一个可以朗读的字母。

若视觉稿只像画笔或橡皮擦，则失败；不能用“滑痕存页”这个名称赋义。若内部两段内容被缩成点线装饰，或被读作两处随机孔洞，无法看见它们之间的连续关系，也应失败。

## 4. 重复风险、小尺寸与单色风险

与 01 的区分在于主体不是取景边界或屏幕轮廓，没有闭合长框、角标和边界突破。与 02 的区分在于没有重叠卡片、拼接缝或对位模块。与 06 的区分在于不画像素采样、多段新增条带或递增三横条。与 07 存在明确的内容语义交集：本稿使用两个内容段作为留存证据，但**主要外轮廓由滚动滑痕决定**，不把文章、聊天、列表版式本身当主标识。总审应比较具体轮廓，不能仅按所属领域判断不同。

与旧稿的禁止结构无关：无 S/Z 折带、闪电、门洞、分段 0、动物或软尺。也不靠配色、材质或透视制造差异。

单色是默认构成方式：实色的运动痕迹与贯通的内容负空间。小尺寸风险是连接上下内容的边栏变细后消失，造成两个孔洞或普通图案。后续制作应先保证负空间边栏宽度，再减小内容段数量；本概念固定只用两段，不增加第三段凑节奏。尚无图稿，未验证 24 px 可用。

## 5. 两个官方参考来源与提炼原则

已完成 web 搜索并打开以下官方来源。研究对象是成熟产品的表达原理，不照描其图标。

1. **Apple，Take and edit Live Photos。** 官方说明 Live Photos 记录拍摄前后各 1.5 秒，并可选择其中的关键照片。[官方产品说明](https://support.apple.com/en-gb/104966)。**设计推断：** 时间跨度可以围绕一个被保留的内容主体表达，不必排出多张完整卡片。本稿让两个先后遇到的内容段留在一个贯通的内容负空间中；没有借用 Apple 的同心圆图标，也不暗示动态图输出。

2. **Google Pixel，Pixel 6’s camera combines hardware, software and ML。** 官方介绍 Motion Mode 的 Action Pan 与 Long Exposure，在静态照片中留下运动的痕迹。[官方产品文章](https://blog.google/products-and-platforms/devices/pixel/pixel-6s-camera-combines-hardware-software-and-ml/)。**设计推断：** 运动可以直接决定画面的整体组织，而不只作为附加符号。本稿让滑动轨迹决定外轮廓，留存内容决定内部结构；使用清楚的实体轮廓，不使用模糊，避免暗示截图画面会糊。

两项来源支持的是“运动或时间能够落在一幅保存结果中”。将其转译为“宽滑痕里显出连续内容”是本 agent 的设计判断，不是来源制定的 Logo 规则。

## 6. 被淘汰的概念与理由

**第二个独立概念：扫描光带。** 一根窄的横向捕获线向下移动，后方形成完整的纵向画面；轮廓上保留一条前倾的宽光带。淘汰原因是第一眼更像文档扫描、条码读取或 OCR，会让人期待摄像头扫描实物；光带的线条累积又容易进入新增条带领域。

**首轮主概念：拖影长帧，已被总审淘汰。** 一张闭合细长画面上添加两条短尾迹。问题是主要结构仍是长方框，运动只是附加装饰；它会和取景、长图方向共享同一个主体。本次改为让滑动动作形成完整外轮廓，并把内容直接留在内部，禁止回退到长框加速度线的构图。
