# 功能语义与去重登记

这里记录主 agent 的概念总审，不等于用户批准，也不替代实际图形检查。

| 组 | 登记主概念 | 当前判断 | 后续图形检查重点 |
| --- | --- | --- | --- |
| 01 | 穿框长页 | 可进入图稿验证 | 四角是取景范围，连续长页越界；避免打印机或扫描仪轮廓 |
| 02 | 共区长窗 | 可进入图稿验证 | 两来源框的内部重复边实际消失，长窗口贯通；避免复制文件和数字 0 |
| 03 | 滑痕存页 | 首稿退回，修订稿可验证 | 动作决定整体外形，内容负空间连接；避免画笔和一般弯条 |
| 04 | 共横接页 | 可进入图稿验证 | 真实共笔而非压字距，读成连页；与印记方向保持不同字形语言 |
| 05 | 一格长底片 | 打印机首稿退回，修订稿可验证 | 一格完整页面图像与成像裁片；电影/滤镜联想不得压过截图身份 |
| 06 | 补行成图 | 可进入图稿验证 | 同幅画面跨底部新增带接续，不能只是像素绘画或进度图 |
| 07 | 续上的图文 | 长框首稿退回，修订稿可验证 | 去掉完整画布框，由图文轮廓与非贯通切缝体现连续留存 |
| 08 | 同页翻转 | 合围槽首稿退回，修订稿可验证 | 同一页在两个观察范围中黑白换底，避免 I 字和双窗建筑 |
| 09 | 贯缝实印 | 厚长框首稿退回，修订稿可验证 | 双瓣实体与画面同时跨缝相续，避免绷带/票券或认证能力暗示 |

## 已拦截的重复或语义问题

- 03「拖影长帧」：闭合长框加两条尾迹，核心与其他长图框方向相同；已改为滑动印迹内留存连续内容。
- 05「长幅出纸机」：功能对应有一定依据，但最直接表达实体打印；需要换主主体。
- 07「跨屏长栏」：长画布配边界线与 01 同构风险高，内容仅作内饰时不能通过。
- 08「共页视口」：三个交替开口的视口夹白色长页，与旧轮次三片合围/分段 0 接近；已要求换主体关系。
- 09「连幅压印」：厚长框加侧缺口仍是长图框的风格变体；已改为双瓣印面与内部图像共同跨缝接续。

## 跨组需要实际比较的关系

01 与 02 都使用画面边界，须分别形成取景范围被穿越、多个来源边界消失两个不同主体关系。02 与 06 都涉及接合，须分别保留双捕获范围、单幅像素面新增带的差异。03 与 07 都保留内容，须分别由运动轮廓、内容版式承担第一视觉主体。04 与 09 都可能像印记，须分别维持现代可读字形、记录识别凭记的形态。

如果无名称、无颜色、无图标底板时仍是同一主轮廓，只变化解释、内容装饰或材质，退回，不计数。

## 图稿总审结果

九条独立概念现均形成可见图稿。独立领域和文字构想不等于实际图形已经通过去重或功能识别，当前结果如下：

| 组 | 当前结果 | 原因 |
| --- | --- | --- |
| 01 | 保留精修价值 | 越过取景范围的长图最直接；品牌独特性仍不足 |
| 02 | 保留精修价值 | 准确几何已修正来源宽度和贯通内窗；仍需降低连接器与文档合并误认 |
| 03 | 淘汰当前构形 | 有机滑痕先像人物、字母或绘画工具 |
| 04 | 保留字标精修价值 | 共笔将名称和连接关系合一；尚未证明可作为小图标 |
| 05 | 淘汰当前主 Logo 构形 | 胶片身份压过截图身份 |
| 06 | 辅助视觉研究 | 新增图像带可见；像素相册或绘画联想较强 |
| 07 | 辅助视觉研究 | 内容轮廓仍先读成版式或阅读工具 |
| 08 | 淘汰当前构形 | 图底关系成立但先像 I、棋盘或机械块 |
| 09 | 淘汰当前构形 | 准确绘制后仍像 8、沙漏或票券，合围孔洞的重复风险没有消除 |

完整原图、实际方法、来源和评审见 `review/review.md`。没有把九条研究方向全部计成九枚可继续的候选，也没有 Logo 定稿。
