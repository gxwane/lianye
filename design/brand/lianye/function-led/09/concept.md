# 09｜贯缝实印（重提）

## 1. 主概念与具体结构

凭记是一块连续着墨的实心印纹，外形近似竖立的双瓣拓片，宽高约 1∶1.8。上瓣偏方、下瓣稍长，两个瓣在中部通过约半幅宽的着墨面相连；主体没有外框，也没有贯穿全高的白槽。在两瓣相接处，左右各有一道宽而浅的直角空切，显示上一屏的下沿和下一屏的上沿。两道空切齐高，不能错位组成 S 或 Z。上瓣内部有一块横向白色画面，下瓣有它向下延伸的同宽白色画面；两者在接缝处经一条较宽的白色斜岸相续，组成一张跨屏的简化景物图。白色图形呈两个面而非长条：上面偏横、下面偏竖，接续处保留清楚的共同岸线。外部印纹与内部图像都必须跨缝连续。

## 2. 可见产品动作

直角空切让两个原始屏幕范围仍可辨认，但画面中的共同岸线穿过屏界，显示它们属于同一个向下延伸的画面。黑色压印面也跨过屏界，使上下两部分成为一枚完整印迹。主动作是“原本受两次屏幕边界限制的图像，留成一个连续记录”。凭记的完整性由印面与画面同时不断开决定，删除中间接续后便会成为两个独立截图片段。此处呈现的是捕获结果，不表示认证、防篡改或安全能力。

## 3. 无名称时的误认与处理

双瓣外形可能被看成绷带、竖向票券，内部岸线可能让人想到普通照片工具。空切采用屏幕的直角，避免绷带的圆孔；外形没有齿孔、编号、蜡封边或奖章挂带。内部只保留一个跨界景物轮廓，不放山峰、太阳等现成相册图标。需要无名称视觉检验，确认先看见两个连续的图像范围，而不是把双瓣直接读成印章物件。

## 4. 重复、缩小与单色风险

与 02 的接合、08 的整体图底存在语义交叉；本案的主构形是两次屏幕范围压成同一枚实印，形体与图像各有一次跨缝接续，未采用长方框、围槽条带或文件附加徽章。与此前方案的具体差异是实体双瓣、横竖两个图像面和共同岸线，不依赖加厚、切角或印章材质。风险在于接续过细会变成链环，岸线转折过强会像折带；两处接续都要宽，斜岸只能出现一次。小尺寸可先保留两瓣、直角空切和共同岸线，尚未证明 24 px 清楚可用。

## 5. 官方参考与设计推断

[Leica 官方合作新闻稿](https://leica-camera.com/sites/default/files/2022-05/press_release_xiaomi_and_leica_camera_announce_long-term_strategic_cooperation_0.pdf)提及红点品牌识别。推断：识别凭记应集中为一个容易留下整体印象的形体。本案借其集中性，不借圆形、品牌字或相机结构。

[Moleskine Classic Notebook Expanded 官方产品页](https://www.moleskine.com/en-us/shop/notebooks/the-original-notebook/classic-notebook-expanded-black-8058647628035.html)列出弹性封带、纸腰封等结构。推断：封存关系可以成为对象自身结构的一部分。本案把这个原则转换为印迹的跨缝连成一体，未采用笔记本或封带外形。

## 6. 淘汰案：双屏合戳

第二案为两枚上下相邻的方戳，各露一半截图轮廓，中间用相同的半圆印文对合。虽然“对上即完整”清楚，但两枚戳仍会被看成盖章认证；中间半圆也容易成为链环或双圆品牌变体，画面连续性让位于印文对合，因此淘汰。上一版“连幅压印”的长框与侧缺口方案撤回，不作视觉候选。
