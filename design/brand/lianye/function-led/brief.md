# 连页：以产品功能为起点的独立 Logo 探索

日期：2026-10-05。用户要求增加真正不同的方向、风格和设计思路，并指出上一轮没有体现产品功能。

## 产品事实与阶段

名称已确认：连页。Android 自动长截图工具，在目标应用中连续截取画面、模拟滚动，匹配相邻画面的重叠区域，将新增内容连接为一张长图。用户随后检查、裁剪、实色遮盖、保存或分享。处理在本机完成，无网络权限。

当前仅探索 Logo，不更改应用或进入交互原型，不提交 Git。现有正式应用、测试包与数据保持原状。此前三份几何切面、软尺、壁虎稿退出优先候选；上一轮对 A 的推荐撤回，因为它没有建立清楚的产品关系。

## 核心设计要求

主标识优先体现「越过一屏，把连续内容接成一张长图」。Logo 无须把编辑、隐私和导出全部堆进去。必须能指出一个可见结构对应产品动作；不能仅借名称或故事把不相关物体解释成连续。

每位 agent 独立探索两个概念，淘汰一个，提交一个主概念。先登记文字概念，主 agent 检查语义与重复后才能制作视觉稿。各组不能读取其他组的方案、图形或旧轮次图稿。研究至少两个相关成熟品牌的官方来源，借鉴构图原则或风格，不能照描品牌形状。

## 九个探索领域

| 编号 | 独占的设计思路 | 风格范围 | 重点产品动作 |
| --- | --- | --- | --- |
| 01 | 取景边界与边界突破 | 精密工业线条、克制构图 | 从屏幕可见范围继续向下截取 |
| 02 | 对位、重叠消除与接合 | 平面构成、模块几何 | 相邻画面匹配后形成完整画面 |
| 03 | 运动与时间被留成画面 | 动态图形、方向节奏 | 自动滚动过程中持续捕获 |
| 04 | 名称本身成为识别图形 | 定制中文字体、字形连接 | 连与页的字形同时体现连续画面 |
| 05 | 成像或输出物件的类比 | 精炼物件、有限材质层次 | 数字屏幕内容成为一张可保存长图 |
| 06 | 像素、采样与新增条带 | 数字构成、栅格与像素语言 | 新增像素逐段累积成完整图片 |
| 07 | 内容与版式的完整留存 | 编辑设计、内容轮廓 | 文章、对话、列表跨屏保留 |
| 08 | 从多个视图看见同一整体 | 单色负空间、图底关系 | 多屏成为一张连续长图 |
| 09 | 完整记录的识别凭记 | 当代徽记、印记与封存 | 长截图保留下来的完整记录 |

领域是设计出发点，不是主 agent 预画的形状；具体构形由各组决定。小尺寸、单色和功能语义要同时考虑。

## 淘汰规则

- 不相关的动物、软尺或抽象徽形，依赖解说才能与产品相连。
- 仅换配色、材质、圆角或透视，把同一构形计为多个方向。
- 延用此前 S/Z 折带、闪电、基础门洞、分段数字 0、递增三横条、一般粗体汉字。
- 相机、相册、剪刀、锁、云、链条、箭头等通用符号的直接照搬；若使用其结构，必须形成可辨的原创整体。
- 不属于已实现产品能力的承诺，如任意页面百分百成功、云同步、智能内容分页。

## 概念提交字段

1. 一个短方向名、图形的具体结构，不用营销形容词代替形状。
2. 图上哪一部分对应截图、滚动、对位、长图或完整留存，主动作是什么。
3. 不显示名称时可能被误认为什么，如何避免错误品类联想。
4. 与其他领域和旧稿的重复风险；小尺寸与单色风险。
5. 两个官方参考来源及提炼的原则，明确哪些是设计推断。
6. 第二个被淘汰的概念与淘汰理由。

## 总审方法

九个概念全部登记后，再检查主体、轮廓、负空间、部件关系和第一眼品类联想。相同主构形不因故事或风格不同而通过。每一稿需要同时具有独立风格和功能证据。完成的图稿逐一查看；不能只审 agent 的设计说明。

展示时区分品牌方向与正式资产。生成式稿件不宣称矢量、24 px 可用、原创唯一或已通过商标检索。
