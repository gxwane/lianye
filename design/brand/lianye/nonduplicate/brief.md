# 连页：不重复的 Logo 探索

日期：2026-10-05。

用户否定上一轮九稿，要求多个 agent 不允许重复，并允许借鉴现成优秀 Logo 的设计风格。名字「连页」仍已确认。范围只包括品牌设计探索，先确定 Logo，再进入交互原型；不改应用、不提交 Git。

## 三个互斥领域

| Agent | 独占领域 | 允许的主体 | 不允许进入的领域 |
| --- | --- | --- | --- |
| Alpha | 几何与负空间 | 抽象几何主体，关系体现在轮廓与留白 | 具象物件、纸张、角色、文字 |
| Beta | 具象物件与材质 | 一眼能认出的单一物件，结构先于光影 | 抽象符号、角色、文字 |
| Gamma | 生物角色与有机轮廓 | 非纸张生物，具有明确姿态和轮廓 | 物件、屏幕、抽象几何、文字 |

各组必须先浏览至少三个成熟品牌的官方产品、品牌或设计来源，记录来源与可借鉴的构图原则。不得照描标志，也不得只换颜色、圆角或渲染质感就将同一轮廓计为新方向。

## 明确淘汰的构形

本轮不继续上一轮的 S/Z 折带、闪电、粗体汉字、门洞、分段数字 0、递增横条、手机边框、重叠纸页。不同角度、比例、笔画粗细与配色不改变这些构形的所属类别。

## 去重检查

先提交概念登记，再制作图形；每组只保留一个主方向。根 agent 比较主体类别、外轮廓、负空间、部件关系和第一眼联想：

1. 同一主体经过颜色、曲率或材质变化仍算重复。
2. 同样的部件关系换名仍算重复。
3. 差异必须在无名称、无容器、单色状态下依然可见。
4. 与其他组或已淘汰构形接近的稿退回重做，不凑展示数量。

概念去重通过后绘制，每组保持独立；完成后再横向核验实际图形，而不是只审核设计说明。

本轮展示目标是三份不同主体与构形的设计方向，不声称这些标识已经定稿或经过商标检索。

## 概念登记结果

Alpha 的首个登记「两个齐平块面夹出收窄通道」已退回：双括号与暂停符号的第一印象过强。重新登记后通过「贯面」：一个不对称钝三角外轮廓，短平肩与大圆腹，通过一条宽弧负形穿透，分出大小不同的区域。参考 Vercel 的少元素、Dropbox 的稳定几何系统、IBM 的正反形光学校正，不借用三家原图形。

Beta 登记通过「延尺」：真实裁缝软尺的压紧卷体、近直宽尾、短银色端头，采用精炼哑光材质与有限刻痕。参考 Things 的物件身份保持、GarageBand 的主物件体量、Paste 的色域与明暗控制。

Gamma 登记通过「接步」：完整壁虎的四肢、躯干与渐细尾巴，以不对称探掌呈现接续动作。参考 Duolingo 的轮廓先行、GitHub 的主标识与角色插画分工、Mailchimp 的克制稳定神态。尺蠖因拱形重复门洞而提前淘汰。

这三个登记分别为抽象切面、单一真实物件、完整生物形态，先以构形关系去重。正式展示前仍须检查实际图稿，不能以登记文字代替图形验收。
