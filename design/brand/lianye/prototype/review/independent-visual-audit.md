# 连页：独立视觉与体验评审

评审依据：实际查看 `overview.png`、`01-home.png`、`02-prepare.png`、`06-result.png`、`07-crop.png`、`12-draft.png`、`16-home-dark.png`；补读 `prototype.js`、`prototype.css` 及应用现有厂商授权引导。未修改原型或应用。名称、首选 Logo、暖白／石墨／烧橙方向保持批准版本。

**结论：品牌方向成立，首页也并不拥挤。最需要减法的是授权、草稿和编辑页面，而不是把所有文字都变小。** 首页已有鲜明的大字、留白和长图越过取景框的图形关系；后续页面却堆入说明、重复状态和精细控件，逐渐呈现“品牌海报＋完整编辑器”的混合感。连页应围绕“截取 → 检查／裁剪 → 保存或分享”组织界面。

视觉层级建议（以当前约 390 dp 宽画面为基准）：

- **首页**：品牌头部 → 30–32 sp 两行标题 → 14–15 sp 一句说明 → 长图示意 → 54–56 dp 高主按钮。维持约 24 dp 横向留白；标题与示意之间保留呼吸空间。减少文案层数，不缩小当前主标题。烧橙由 Logo、示意图局部承担，删除眉题后无需补一个橙色标签。
- **结果**：18–20 sp 页面标题 → 12–13 sp 单行保存状态 → 尽量全宽的图片 → 14 sp“裁剪／查看全图” → 54–56 dp 高“保存图片”及较轻的“分享”。原图是第一视觉焦点，底部最多两层操作，不再放一整排四个编辑工具。分享保留文字，避免简化为无标签图标。
- **裁剪**：18–20 sp 标题与“取消／应用” → 占剩余空间的可读图片 → 一行 12–13 sp 操作提示与全图切换。无需大标题、卡片或四组数据输入。橙色只标裁剪边界和当前手柄，外围遮罩用中性深色，让保留范围与被裁范围直接可辨。

## 厂商帮助必须恢复，但不增加首屏问答

这不是需要探索的新功能。现有 `DeviceVendorDetector.kt` 已识别小米、OPPO／OnePlus／realme、vivo／iQOO、华为／荣耀、三星及通用设备；`PreFlightGuideBottomSheet.kt` 和中文资源已有相应路径。原型只提供通用无障碍页和“不同手机的名称与位置可能不同”，这确实丢失了已有帮助适配。

建议自动显示当前设备的一条路径，不要求用户先选择品牌，也不在首页列出所有系统。举例沿用现有小米资源：

> 小米手机
> 无障碍 → 通用 → 已下载的服务 → 连页
> 开启后返回连页。

当前按钮直接跳转无障碍设置，因此准备弹层可从“无障碍”起显示路径；帮助页再提供完整设置路径。具体路径应复用现有资源，并保留“入口名称可能因系统版本不同。”这条短说明，不能把现有厂商分组包装成已经验证每个系统版本。Android 10 的屏幕捕获授权只在需要它的设备出现。

首页右上用可读的“帮助”或“设置与帮助”替代只有调节图标的入口；44 dp 点击区域照常保留。设置页删除“按你的习惯来。”等装饰标题；使用帮助保留三步：

1. **打开页面**：切换到要截图的 App。
2. **点「截取」**：自动滚动，点「结束」停止。
3. **保存长图**：检查结果，按需裁剪，再保存或分享。

下方放“本机设置路径”和“服务开关无法开启”的具体帮助；电池设置、ADB 等高级排障折叠。不要为了简洁删掉这些解决实际失败的入口，也不要把整份排障说明塞进首次准备。

## 减少打断，而不是删掉必要确认

原型有不少问句式标题和结果弹层。每一步都需要回答，会让轻量工具显得繁琐。授权准备改成直接说明任务；保存成功改为“已保存到相册”的短提示，保留结果页即可，删“完成／继续编辑”成功弹层；分享调用系统选择器，回到结果页，不再弹“已交给所选应用”。停用服务可直接执行并更新状态，它本身可恢复。

仅在新截图将覆盖**未保存**结果时保留应用确认：“新建会替换这张未保存截图。”配“保存后新建／舍弃并新建／取消”。正常返回首页保留草稿，不要求再确认。系统自己的授权窗口继续保留；保存失败和截取中断要明确说明已有内容是否保留，并提供“重新保存／重新截取”，不能为画面干净而隐藏。

遮盖隐私按用户要求整段删除，包括工具入口、编辑页、相关说明和专为遮盖演示加入的联系号码。关于本机处理的信息集中在授权说明与帮助里即可，不需要反复作为装饰徽章出现。

建议优先顺序：恢复当前机型权限路径 → 删除遮盖 → 修正裁剪预览 → 合并重复状态与成功弹层 → 精简草稿页 → 微调首页与深色模式。设计感主要来自清晰层级、足够图片面积和有节奏的留白；保留帮助、状态、可见操作和大点击区域，简洁才会真正可用。

## V2 独立复核

重新实际查看更新后的 `01-home.png`、`06-result.png`、`07-crop.png`、`07b-crop-overview.png`、`12-draft.png`、`16-home-dark.png` 和 `overview.png`。**这组画面可用于评审，没有必须修的视觉或阅读问题。**

首页保住了两行大标题、暖白留白和越过取景框的纸张，减掉重复文字后仍有辨识度；“帮助”和主按钮也容易找到。结果页的图片获得足够宽度，裁剪／保存／分享集中在一排，主次清楚，保存状态没有再与弹层竞争。裁剪默认显示可读内容，“查看全图／放大调整”提供明确切换；全图模式的小字是定位缩略图的合理结果，不再承担精细编辑。草稿页从品牌海报转为具体任务，缩略图、未保存状态与继续编辑组成紧凑的动作组。深色首页的标题和按钮对比清晰，示意纸张虽较暗，轮廓与结构仍能辨认，不构成阅读阻碍。

总览中的准备弹层已恢复一条当前机型路径，没有增加品牌选择步骤；自动截取也把屏数与结束合到一个控制区。当前减法同时改善了安静感和可发现性，无需为追求更少元素再删掉状态、帮助或操作文字。上一轮提出的深色承载底等微调不作为本轮评审前置条件。
